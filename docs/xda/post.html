Samsung's One UI 8.0 (Galaxy S23 firmware, Android 16) running on the Mi 11 Lite 5G, on renoir's own MIUI vendor. SELinux enforcing.

Flash the stock MIUI firmware, then the zip with flash_all.bat (Windows) or flash_all.sh (Linux/macOS) – done. Everything is open source: the GitHub repository has every script and fix that went into the zip, so you can check what's inside – or build the same images yourself from the official firmware.

What works

  • Boot, setup, One UI launcher and Samsung apps
  • Wi-Fi, mobile network (calls/SMS/VoLTE: please report)
  • Bluetooth incl. audio (AirPods etc.)
  • Fingerprint (in-display), unlock
  • Punch-hole cutout, rounded corners, 60/90 Hz, brightness
  • Vibration incl. keyboard haptics
  • Cameras in GCam and third-party apps (see Camera below)
  • Sensors

Known issues

  • adb/USB data needs one cable replug after every boot
  • Samsung Core Services and Theme Center crash once at boot (harmless)
  • Galaxy Store may show error 2300:1004
  • Fingerprint ring animation missing
  • Knox features (Samsung Wallet, Secure Folder, Samsung Pass) won't work
  • Not verified yet: NFC, GPS, call microphone – reports welcome

Camera

There is no camera app in the ROM (Samsung's needs Samsung's camera hardware). Install a GCam port for the Mi 11 Lite 5G (link in Downloads) – it works without problems, as do other camera apps and the camera in browsers and messengers.

Requirements

  • Unlocked bootloader
  • Stock MIUI V14.0.7.0.TKIMIXM (Global) – exactly this version: the ROM keeps its kernel and firmware (modem, audio, camera), and our vendor's drivers only match this build. Already on it? Skip step 1 below.
  • Android platform-tools (fastboot); on Windows the Xiaomi/Google USB driver

Downloads

  • Stock MIUI V14.0.7.0.TKIMIXM fastboot ROM (official Xiaomi server, 6.3 GB) – step 1
  • One UI 8.0 for renoir – flashable zip (6.0 GB) – step 2
    SHA256: 13b35663cdbc1fb07a4d3bebe4910a5595345b2a23e6875e830a5d82a982e8ff
  • GCam ports (camera app)
  • Android platform-tools (fastboot)

Install

Flashing erases all data.
  1. Stock firmware: unpack the MIUI .tgz, phone in fastboot (off, hold Power + Volume down, USB), run flash_all.bat / flash_all.sh from it – or MiFlash with "clean all".
    Do NOT use flash_all_lock / "clean all and lock" – it relocks the bootloader.
    No need to set up MIUI afterwards: go back to fastboot (Power + Volume down) and continue.
  2. One UI: unzip the ROM zip, phone in fastboot, run flash_all.bat (Windows) or ./flash_all.sh (Linux/macOS), type YES.
  3. The first boot takes 5–10 minutes.
  4. Install a GCam port for the camera.
Back to MIUI: step 1 again.
